# 🧮 Calculadora Interativa em Java

## 📖 Descrição

Este projeto é uma calculadora interativa desenvolvida em Java para praticar os conceitos básicos da linguagem, como entrada de dados pelo usuário, estruturas condicionais e operações matemáticas.

A aplicação é executada pelo terminal e permite ao usuário escolher uma operação matemática e informar dois números para realizar o cálculo.

## 🚀 Funcionalidades

A calculadora realiza as seguintes operações:

* ➕ Soma (`somar`)
* ➖ Subtração (`menos`)
* ✖️ Multiplicação (`vezes`)
* ➗ Divisão (`dividir`)

Caso uma operação inválida seja informada, o sistema exibe uma mensagem de erro.

## 🛠️ Tecnologias Utilizadas

* Java
* Scanner (`java.util.Scanner`)
* Estruturas condicionais (`if` / `else if`)

## 📋 Como Funciona

Ao executar o programa, o usuário deve:

1. Informar a operação desejada.
2. Digitar o primeiro número.
3. Digitar o segundo número.
4. Receber o resultado da operação escolhida.

### Exemplo de uso

```text
Qual operação deseja fazer:
somar

Digite o primeiro numero
10

Digite o segundo numero
5

A soma é: 15
```

## ▶️ Como Executar

### Compilar

```bash
javac InterativeCalculate.java
```

### Executar

```bash
java InterativeCalculate
```
